# ⚡ Quick Start Guide

## 🎯 5-Minute Setup

### 1️⃣ **Open the Application**
   - Find `index.html` in the `video_to_audio` folder
   - Double-click it (or open in your browser)
   - Wait for: `✅ Ready to use` (usually 10-15 seconds)

### 2️⃣ **Upload Your Video**
   - Click the upload zone
   - Select a video file OR drag-and-drop it
   - You'll see the filename and size displayed

### 3️⃣ **Choose Format (Skip for Default)**
   - Default is MP3 (best for most uses)
   - Click any format button to change
   - Popular choices: MP3, WAV, FLAC

### 4️⃣ **Click Convert**
   - Click "Extract & Convert" button
   - Watch the progress bar
   - Usually takes 1-2 minutes for a 100MB video

### 5️⃣ **Download**
   - Click "📥 Download Audio"
   - Audio saves to your Downloads folder
   - Done! ✅

---

## 🎛️ Format Quick Reference

```
🎵 MP3      → Best for everything (portable, small)
🎼 WAV      → Best quality (large, uncompressed)
🔊 FLAC     → Compressed lossless (quality + space)
📱 AAC      → YouTube, streaming (modern)
🎧 OGG      → Open format (web-friendly)
🍎 M4A      → iTunes, Apple devices
```

**For Best Quality:**
- Bitrate: 320 kbps
- Sample Rate: 96 kHz
- Channels: Stereo

**Balanced (Recommended):**
- Bitrate: 192 kbps
- Sample Rate: 44.1 kHz
- Channels: Stereo

## ❓ Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| FFmpeg won't load | Refresh page, check internet |
| Conversion too slow | Close other tabs, use lower bitrate |
| File size too large | Try FLAC or lower bitrate |
| Audio quality bad | Increase bitrate to 256-320 |
| Download doesn't work | Check browser download settings |
