## Format & Quality Questions

### Q11: Which format should I use?
**A:** Depends on your use:

**For general listening:**
→ MP3 (192 kbps) - universal, small file

**For maximum quality:**
→ FLAC or WAV - lossless, larger file

**For Apple devices:**
→ M4A or AAC - iTunes compatible

**For web/streaming:**
→ AAC or OGG - modern compression

**For podcasts:**
→ MP3 (128 kbps) - good quality, small file

---

### Q12: What does bitrate mean?
**A:** Bitrate = audio quality vs file size

- **128 kbps**: Acceptable quality, smallest file
- **192 kbps**: Good balance (recommended)
- **256 kbps**: High quality
- **320 kbps**: Maximum quality, largest file

**General rule:** Higher = Better quality + Larger file

---

### Q13: What's the difference between sample rates?
**A:** Sample rate = frequency precision

- **44.1 kHz**: CD quality, most compatible ✅
- **48 kHz**: Professional/broadcast audio
- **96 kHz**: Audiophile/high-resolution audio

**Most people:** Use 44.1 kHz (CD quality)

---

### Q14: Should I use stereo or mono?
**A:** Depends on content:

- **Stereo**: Full hearing experience
  - Music
  - Movies
  - Professional audio

- **Mono**: Space-saving
  - Podcasts
  - Audiobooks
  - Dialog

**Default:** Use stereo for best quality

## Troubleshooting Questions

### Q15: FFmpeg won't load - what should I do?
**A:** Try these steps in order:

1. **Refresh page**: Ctrl+R
2. **Clear cache**: Ctrl+Shift+Del
3. **Wait longer**: Up to 30 seconds on slow internet
4. **Check internet**: Try other website
5. **Try different browser**: Usually Chrome works fastest
6. **Restart browser**: Close all windows, reopen

If still fails → see TROUBLESHOOTING.md

---

### Q16: Conversion failed - what went wrong?
**A:** Several possibilities:

**Most likely:**
- Unsupported video codec
- Corrupted video file
- Insufficient memory

**Solutions:**
1. Try smaller video file
2. Try different output format
3. Close other apps (free RAM)
4. Convert video to MP4 first
5. Try different browser

See TROUBLESHOOTING.md for more details.

---

### Q17: Audio quality is bad - why?
**A:** Usually bitrate too low.

**Fix:**
1. Click Advanced Options
2. Increase bitrate to 256-320 kbps
3. Try again

**Or try lossless:**
- Use FLAC or WAV format
- Preserves perfect quality

---

### Q18: Download not working - what should I do?
**A:** Try these steps:

1. **Check browser settings**:
   - Chrome: Settings → Privacy → Downloads
   - Firefox: Preferences → Files
   - Enable downloads

2. **Check download folder**:
   - Look in Downloads folder
   - May have been saved there

3. **Save manually**:
   - Right-click download link
   - Select "Save as"
   - Choose location

If still failing → see TROUBLESHOOTING.md
