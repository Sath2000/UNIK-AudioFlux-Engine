# 🎯 Getting Started (Complete Beginner Guide)

## 1️⃣ Open The App

Open **`index.html`** in your browser:
- **Windows**: Double-click the file
- **Mac**: Double-click the file
- **Mobile**: Open with your phone's browser

That's it! You're ready to go. ✅

---

## 2️⃣ Wait For Ready Signal

You'll see a loading badge at the top:
- ⏳ "Loading FFmpeg..." (wait 10-15 seconds)
- ✅ "Ready to use" (you're good to go!)

☀️ **Tip**: This only happens the first time. Subsequent uses are much faster!

---

## 3️⃣ Upload Your Video

**Choose one:**

**Option A: Click to browse**
- Click the big upload zone
- Select a video file
- Any format works!

**Option B: Drag & drop**
- Drag your video file
- Drop it on the upload zone
- Done!

You'll see:
- 📹 Video filename
- 📊 File size
- ✓ Ready to convert

---

## 4️⃣ Pick Audio Format (Optional)

Default is **MP3** - it works great for everything!

But you can choose others:
- 🎵 **MP3** ← Default, use this!
- 🎼 **WAV** - High quality
- 🔊 **AAC** - For Apple devices
- 🎧 **FLAC** - Lossless quality
- 🎶 **OGG** - Open format
- 🍎 **M4A** - iTunes

Click any button to switch.

---

## 5️⃣ Customize Quality (Optional)

**Advanced options?** Click "⚙️ Advanced Options" to see:
- Bitrate (128-320 kbps)
- Sample rate (44.1-96 kHz)
- Channels (Mono/Stereo)

**For beginners:** Leave these as default! 👍

---

## 6️⃣ Convert!

Click the big **"Extract & Convert"** button

You'll see:
- 📊 Progress bar fills up
- ⏱️ "Converting..." message
- Expected time based on file size

**Just wait!** Don't close this window.

---

## 7️⃣ Download

When done, you'll see:
- ✅ "Conversion Complete!"
- 📥 Download button

Click **"📥 Download Audio"** and your audio file saves!

---

```

```

```
🎧 After effects     → AAC
🎶 Music streaming   → FLAC (if service supports)
```

## ⚠️ Common Questions

**Q: Where are my files stored?**
A: On YOUR computer only! Nothing goes to servers.

**Q: Do I need WiFi?**
A: Only for the first load (to download FFmpeg).
After that, completely offline!

**Q: Is it safe?**
A: Yes! It's just like any browser app.
Run by FFmpeg (open source, trusted).

**Q: Can I close the browser?**
A: Yes, but conversion stops if you do.
Keep it open while converting.

**Q: What if it crashes?**
A: Just reload and try again!
Your original video is untouched.

**Q: How big can files be?**
A: Browser allows 2-4 GB typically.
Most videos are < 1 GB anyway.

## 🎯 Pro Tips

### Tip 1: Start Small
Try a 100MB video first to test!
Then do bigger ones.

### Tip 2: Keep Browser Window Open
Don't close or minimize during conversion.
Let it run untouched.

### Tip 3: Close Other Apps
Speeds up conversion:
- Close Word, Excel, Chrome tabs
- More free RAM = Faster processing

### Tip 4: Use Chrome or Edge
Fastest browsers for this task.
Firefox is close second.

### Tip 5: Downloaded Files
Saved to your **Downloads folder**
- Windows: `C:\Users\YourName\Downloads`
- Mac: `~/Downloads`
- Mobile: Your device's Files app

## 🐛 Something Not Working?

### Issue: FFmpeg Won't Load
```
✅ Solution: Refresh page (Ctrl+R)
✅ Wait: Up to 20 seconds
✅ Check: Internet connection
✅ Try: Different browser
```

### Issue: Conversion Fails
```
✅ Solution: Try smaller video (< 500 MB)
✅ Try: Different output format
✅ Close: Other apps (free memory)
✅ Restart: Browser completely
```

### Issue: Download Not Working
```
✅ Check: Downloads folder
✅ Allow: Browser download permission
✅ Try: Right-click → Save as
```
